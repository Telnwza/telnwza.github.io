## วิธีใช้ Import

1. เปิดโปรเจกต์ปลายทาง และเลือก schematic ที่จะวางบล็อก
2. ไปที่ **File → Import Project as Sub-project…** หรือปุ่ม **↓** ข้าง PROJECTS
3. เลือก `.schproj.json` เดิม ถ้าเป็น Workspace หลายโปรเจกต์ ให้เลือกโปรเจกต์ต้นทาง
4. เลือก **Sub-block ใน schematic ปัจจุบัน**, **โปรเจกต์ใหม่ใน Workspace** หรือ **Schematics ในโปรเจกต์ปัจจุบัน** แล้วกด **นำเข้า**

ตัวนำเข้าเก็บทุกแผ่นและ custom component ของต้นทาง สร้าง ID ใหม่สำหรับแผ่น/ชิ้นส่วน/สาย แก้การอ้างอิง SCH/CUSTOM และเติมเลขต่อท้ายชื่อที่ชนกัน โดยคง Top เดิมของปลายทางไว้เมื่อเลือก sub-block สามารถ Undo/Redo ได้ทั้งการนำเข้าและการแยกโปรเจกต์ การวาง sub-block จะเลือกตัวบล็อกให้ลากต่อได้; พอร์ตภายนอกยังต้องต่อสายตามวงจรที่ต้องการ

**Save Workspace บันทึกทุกโปรเจกต์ ส่วน Open Project / Workspace โหลดมาแทน Workspace ที่เปิดอยู่** ถ้าต้องการเพิ่มงานโดยเก็บของปัจจุบัน ให้ใช้ Import

## แก้เพิ่มเติมระหว่างรวม

- การโหลด Workspace เตรียมทุกโปรเจกต์ให้ครบก่อนเปลี่ยนข้อมูลจริง; ถ้าไฟล์ใดเสียจะไม่เหลือสถานะโหลดเพียงบางส่วน
- Undo/Redo เก็บทั้ง Workspace จึงคืนการย้ายระหว่างโปรเจกต์ได้ครบ
- การคัดลอกไปโปรเจกต์ที่มี custom component ชื่อเดียวกันจะสร้างชื่อใหม่และแก้ reference แทนการใช้วงจรเดิมผิดตัว
- ป้องกัน ID โปรเจกต์ใหม่ชนกับโปรเจกต์ที่โหลดมา และไม่สลับโปรเจกต์ระหว่าง Placement Mode
- ตัดบิตจาก CONST โดยคำนวณ literal ที่ต้องการก่อนสร้าง VHDL; รูป `x"F4"(7 downto 4)` จากไฟล์ใหม่คอมไพล์ไม่ผ่าน
- เมื่อ preset ผูก VCC แต่ reset เป็นสัญญาณ ยังให้ reset มีลำดับสูงกว่า รวมถึงกรณีไม่มี clock
- ล้างข้อมูลบัสชั่วคราวก่อน Generate ซ้ำ ป้องกันสัญญาณเก่าติดอยู่หลังลบ merge taps

ข้อจำกัด: เป็นการทดสอบด้วยไฟล์ตัวอย่างใน `fixtures/import-v1.schproj.json` และข้อมูลจำลอง ไม่ใช่การรับรองโปรเจกต์เก่าทุกไฟล์ ยังไม่ได้ทดสอบ Vivado implementation หรือบอร์ดจริง หากไฟล์เก่ามีชนิด component ที่ไม่รองรับ, reference ขาด หรือวงจรอ้างอิงวนซ้ำ ตัว import จะปฏิเสธพร้อมสาเหตุโดยเก็บงานปัจจุบันไว้

Custom component ที่เก็บเป็น VHDL ข้อความและมีชื่อ entity/dependency ชนกัน ต้องเปลี่ยนชื่อในต้นทางก่อนนำเข้า เพราะการเปลี่ยนชื่อข้อความโดยไม่ parse VHDL อาจเปลี่ยนพอร์ตหรือสัญญาณผิดตัว ส่วน custom ที่เก็บเป็น schematic เปลี่ยนชื่อพร้อม reference ได้อัตโนมัติ

เปิดไฟล์ Workspace v2 ด้วยเว็บเก่าที่รู้จักเฉพาะ v1 จะเห็นได้เพียงโปรเจกต์ active ในฟิลด์ `project`; เว็บเก่าไม่รู้จักรายการโปรเจกต์ทั้งหมด และไม่รองรับวงจรใหม่อย่าง CONST/Bus Tap หลายบิต จึงควรใช้เวอร์ชันที่รวมแล้วในการแก้ไขไฟล์ v2
